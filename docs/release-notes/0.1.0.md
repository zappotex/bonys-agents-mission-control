Erstes Release von **Bony's Agents Mission Control** – vorbereitet für die automatische Installation in Agent-PCs von Bony's Agents (Debian 13, amd64 und arm64).

**Installation**

```bash
curl -fsSLo /tmp/mc-install.sh https://github.com/zappotex/bonys-agents-mission-control/releases/download/v0.1.0/install.sh
sudo bash /tmp/mc-install.sh --version 0.1.0 --install-deps
```

Danach: http://127.0.0.1:8787/ (nur lokal). Details: [docs/installation-agent-pc.md](https://github.com/zappotex/bonys-agents-mission-control/blob/v0.1.0/docs/installation-agent-pc.md)
