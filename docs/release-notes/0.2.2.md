# Mission Control 0.2.2

## Update-Zentrum und manuelle Aktualisierung

- Die README dokumentiert die manuelle Aktualisierung mit fester Version, `latest`, Bundle-Update und Healthcheck.
- Mission Control erhält den Bereich **Updates**.
- Die Oberfläche kann die neueste offizielle GitHub-Version prüfen.
- Ein verfügbares Update wird mit Release-Link und sicher erzeugtem `update.sh`-Befehl angezeigt.
- Der Befehl kann kopiert werden.
- Die Oberfläche führt keine Root-Kommandos selbst aus; dadurch bleiben Administratorrechte und die Freigabe beim Betreiber.
- Release-Antworten, Versionen und Release-URLs werden streng validiert.
