# Mission Control 0.2.1

Status: PATCH-RELEASE

Mission Control 0.2.1 behebt den lokalen Docker-Zugriff auf das Mission Board. Die lokale Veröffentlichung bleibt auf `127.0.0.1` begrenzt; externe Backend-Bindungen benötigen weiterhin einen Bearer-Token.

## Änderungen

- Lokale Docker-Veröffentlichungen erlauben Missionslesezugriff ohne Browser-Token, wenn der Host ausschließlich über Loopback veröffentlicht wird.
- Externe Hostnamen und externe Backend-Bindungen bleiben tokenpflichtig.
- Neue Regressionstests sichern beide Pfade: lokaler Loopback-Zugriff und geschützter externer Zugriff.
- `MISSION_CONTROL_LOCAL_ONLY=true` wird in der lokalen Compose-Installation standardmäßig gesetzt.

## Upgrade

Bestehende 0.2.0-Installationen aktualisieren sich mit:

```bash
sudo /opt/bonys-mission-control/scripts/update.sh --version 0.2.1
```

Missionen, Geheimnisse und das Docker-Daten-Volume bleiben erhalten.
